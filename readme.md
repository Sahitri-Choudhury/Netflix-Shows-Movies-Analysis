# Netflix Titles Analysis

This project is a **data analysis of Netflix titles** using Python, SQL, Excel, and Tableau. The goal is to explore the dataset and generate insights about the content available on Netflix, including trends over time, popular genres, top producing countries, content types, and ratings distribution.  

## Project Overview

The dataset contains information about movies and TV shows available on Netflix, including title, type, director, cast, country, date added, release year, rating, duration, and listed genres. This project aims to clean, analyze, and visualize this data to better understand the characteristics and trends of Netflix content.

## Technologies and Tools Used

- **Python** – for data cleaning, manipulation, and analysis using libraries such as `pandas`, `numpy`, `matplotlib`, and `seaborn`.  
- **SQL** – for querying and aggregating the dataset to extract meaningful information.  
- **Excel** – to perform preliminary exploration and pivot table analysis.  
- **Tableau** – to create interactive dashboards and summarize insights visually.  

## Analysis and Observations

During the analysis, several patterns and insights were observed:  

- **Content Types**: Movies and TV shows are unevenly distributed, with certain periods favoring one type over the other.  
- **Country Production**: A small number of countries produce the majority of content on Netflix.  
- **Popular Genres**: Genres like Drama, Comedy, and Documentaries are the most frequently listed, showing what kind of content is emphasized on the platform.  
- **Content Trends Over Time**: The number of titles added each year has grown steadily, reflecting Netflix’s expansion strategy.  
- **Ratings and Duration**: Most titles have common ratings, and movie durations are clustered around typical lengths, providing insight into audience preferences.  
- **Cast Patterns**: Certain actors appear frequently across multiple titles, indicating recurring collaborations or popular series franchises.  

This project highlights **how data can reveal trends and preferences in streaming content**, providing actionable insights for content analysis and recommendations.
